## [▶ PLAY HORROR TIPS IN YOUR BROWSER](https://tuffm82-pixel.github.io/Horror-tips/)

No installation needed. Open the link and choose **Campaign**.

## [⬇ DOWNLOAD THE GAME](https://github.com/tuffm82-pixel/Horror-tips/raw/refs/heads/main/downloads/Horror-Tips.zip)

1. Download the ZIP file.
2. Extract it (on Windows: right-click → **Extract All**).
3. Open **Horror Tips.html** in your browser.

The downloaded campaign works offline. It is a browser game, not a Windows installer.

**Controls:** WASD to move · mouse to look · Shift to sprint · F for torch · Space to continue or time a step · Escape to pause.

**Multiplayer:** requires a running multiplayer server. See the [setup instructions](README.md#hosting).

If the browser link shows 404, the owner needs to enable **Settings → Pages → Source: GitHub Actions**, then run **Actions → Publish campaign to GitHub Pages → Run workflow**. The downloadable version works independently of Pages.
